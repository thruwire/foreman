# Foreman 0.4.3

This patch reduces Jev input costs and prevents long Codex hook sessions from repeatedly
exceeding the model's context window.

- Validate aggregate request sizes for both assessments and responsibility routing before
  submission. Requests use conservative JSON byte budgets of 30,000 for state plus the longest
  question and 60,000 for state plus all questions.
- Deduplicate worker output on routine requests and aim for soft assessment targets of
  12,000/24,000 bytes. Older history and optional text are reduced with explicit omission markers.
  These reductions run locally without summarization or additional model calls.
- Preserve the full job, current hook operation and tool arguments, selected repository
  instructions, routing bindings, and question definitions. Essential context may exceed the
  soft targets up to the hard limits; essential overflow uses the existing fail-closed handling.
- Recover oversized saved sessions without clearing their history.
- Record API-reported token usage and before/after request sizes in the central
  `jev-usage.jsonl`. Records contain metadata only; missing counts remain unknown.
- Document focused evidence selection for project-context checks and environment controls for
  request targets and hard budgets.

The byte budgets are a conservative proxy, not exact token counts. Existing responsibility
definitions continue to govern decisions, and this release does not add Pi integration.
